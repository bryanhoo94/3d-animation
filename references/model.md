# 量图和搭模型

模型文件（`<名字>-model.js`）只导出三样：`SPEC`（形状、颜色、花纹、零件）、`KEY`（每只的「想」「干活」姿势）、`ACTIONS`（新加的动作，可以没有）。文件里不 import 任何东西。
从 `examples/` 抄最像的一只开始改，别从空白写。

## 坐标

- 量原图时把**身子的半宽**记作 1（在最宽那一行量，不算手）。x 右、y 上、z 朝你。y = 0 放在身子中间附近（眼睛下面一点）。
- `SPEC.skins.<皮>.ref = { image, unit, cx, cy }`：unit、cx、cy 都是**除以原图宽度**的比例（原图 2000 宽、半宽 570px → unit 0.285）。overlay 工具靠它对齐。
- `SPEC.frame = { K: 0.76, FLOOR: -0.83, GROUND }`：K 和 FLOOR 别改（每只都放进同一个画框、一样高）；GROUND 是**脚底在身子坐标里的 y**，量出来填。

## 量（tools/measure.py）

1. `python3 -I tools/measure.py 原图.jpg --mask m.png --rows 30`：先看 m.png 抠得对不对。脚下有影子就加 `--floor <脚底那一行 px>` 切掉；底不干净就调 `--thr`。
2. 在 `rows` 里找身子：每一行的 `runs` 是实的几段；手、耳朵要么是另外一段，要么是比身子凸出去的部分。身子最宽那一行的半宽（px）当 unit，中点当 cx，选一行当 cy。
   - 最宽那一行被手（鳍、翅膀）挡住、跟手连成一段：用手下面第一行看得清的身子，按身子的形状往回推。
   - 头顶很亮的反光会让轮廓缺一个口（那几行裂成两段）：对照 `outer` 和上下几行，别把缺口当形状。
3. 再跑 `--unit U --cx X --cy Y --grid g.png`：每行有 `by`（身子坐标的 y）和每段的 `hw`（半宽）、`mid`（中点），照这些数拟合身子的轮廓。
   **里面的花纹边**（白脸那块、围巾上下沿、垂条的下沿、脚趾、肚子底）轮廓量不到，在 g.png 的格子上读（细线 0.1、粗线 0.5）。别凭眼睛估：不看格子，垂条下沿读成 −0.72，实际是 −0.85。
4. `dark`：最大的两块一般是两只眼睛（`body` 是中心、`half` 是半宽半高 → `EYE.x / y / rx / ry`），扁的那块是嘴。最大的一块要是在脚下，那是影子，不是眼睛。
5. `--pick x,y …`：在每个颜色的**亮面**取色（别取在影子里，影子着色器自己会做）。白色、奶油色照取的放会过曝成纯白（亮面要乘 lit 再加高光）：先调低 5–8%，再对着 overlay 看。

## 透视：靠前的零件要往回收

镜头离身子中面 8 个单位，近大远小：**越靠前的点，画出来越往外、越远离镜头的高度**。原图是平的，量出来的数都相当于在中面上。轮廓（身子最宽那一圈就在中面附近）照量的数放就对；脸上、脚上这些靠前的零件照量的数放，会偏外、偏下 5–10%（眼睛偏外 0.04 左右、脚趾偏下 0.07 左右）。

```
镜头高度（身子坐标）c = (0.52 − (FLOOR − GROUND·K)) / K
放大倍数           m = 8 / (8 − z·K)        z：这个点在身子坐标里有多靠前；脸上的点 z ≈ rz·√(hw(y)² − x²)，脚趾 z 就是它的位置
放的 x = 量的 x / m
放的 y = c + (量的 y − c) / m
```
- 眼睛、嘴、腮红、白脸的边、围巾前沿、脚趾、GROUND（脚趾在前面）都要这样收一次。GROUND 收完会动 c，用新的 c 再收一次就够。
- 收完用 `tools/overlay.py` 的数字看：眼睛中心差不到 0.02、最低点差不到 0.02 就行。
- `examples/` 那两只是写这条之前做的，没收：眼睛偏外 0.02–0.06。没改它们，是为了跟线上那两页（Elio 的 /artifact-01、/artifact-02）一模一样；照它们抄的时候，五官和脚的数按这里重新收。

## 身子

`SPEC.body(d, out)`：单位球上的方向 d → 身子表面上的点。kit 用它细分出网格、算法线、把眼睛嘴贴上去。两种写法，挑跟原图像的：

- **上圆顶 ＋ 下胖肚**（`pink`）：上半椭圆（`d.y ** 0.86` 让顶更平），下半按每个高度的半宽 `hwLow(y)` 收（超椭圆，底是平的）。
- **蛋形**（`penguin`）：最宽在 y = c，上半 `A·√(1 − s^P)`、下半 `A·(1 − s^M)^(1/M)`；对 measure 量的十几行拟合 A、P、M、top、bot，误差 < 0.005 就够。
  原图底是平的（玩具放在桌上那种），这个公式收不出平底：在 `body()` 里把低于底线的点用平滑的 max 压到底线上（`y = smax(y, 底线, 0.04)`），轮廓下半截照量的数再对一遍。

`hwAt(y)`（某个高度的半宽）顺手写出来：围巾、垂下来的条、贴肚子的零件都要用。z 方向的厚度用 `rz`（侧面看多扁，原图看不到侧面就 0.92–0.95）。

## 零件（`build(api)` 里搭）

api 给的：`head`（跟着头转：身子、耳朵、围巾都挂这里）、`torso`（不跟着头转：手、脚）、`mesh(geo, 零件号, { lenK, gloss })`、`arm(左右 -1/1, ARM, mesh)`、`blob(形状函数, 细分)`、`ring(fn(u, v), nu, nv)`、`ell(rx, ry, rz, 改形)`、`onFace(x, y)`、`smax`、`sgnPow`、`V3`、`detail`、`skin`。

| 零件 | 怎么搭 | 例子 |
|---|---|---|
| 身子 | `head.add(mesh(blob(body, detail), 0))` | 两只都有 |
| 耳朵 | 一颗椭球，一半埋进头顶两侧，往外歪 | pink `EAR` |
| 手 / 翅膀 / 鳍 | 椭球 ＋ 改形（末端胖一点、扁一点），`arm(s, ARM, m)` 挂到肩膀的轴上；轴藏在围巾或身子里，`ARM.rest` 是垂下来往外斜多少 | pink 连指手套 ＋ 手心肉垫；penguin 扁鳍 |
| 脚 | 腿一截 ＋ 几颗脚趾（pink），或脚掌 ＋ 脚趾（penguin），底都落在 GROUND | |
| 围巾 / 项圈 / 腰带 | `ring`：u 绕身子一圈（截面中心贴着 `hwAt` 往外推一点），v 绕截面一圈（`sgnPow` 做圆鼓鼓的扁方）；前低后高用 `tilt·cos(u)` | 两只都有 |
| 垂下来的条 | 圆角扁方（超椭球）再弯过去贴着肚子（`zOn(x, y)` 是身子前面那点的 z）；跟身子接的地方用 `smax` 接，不然有一道折痕 | pink 两条带罗纹收口；penguin 一条 |
| 肚子那块、脸那块、腮红、条纹、针织纹 | **不建模，画在着色器里**（`alb()`），边缘用 smoothstep 虚一点；软胶要「嵌进去」的感觉就在 `ao` 里给边一道浅影 | pink `bellyN`；penguin `faceD`（顶上两个圆包 ＋ 中间往下一个尖） |
| 竖纹、横纹的凹凸 | 竖纹只改法线（`#define BUMP` ＋ `bump()`），横纹可以在 `ring` 的截面上压槽 | penguin |

经验（都是试出来的）：
- 原图轮廓上看得出的鼓包才建模；平的花纹全画。
- 白脸那块顶上的线过了圆包还要接着往下掉，交给两侧那条线收（平滑的 min），不然拐角留一道台阶。只有**外侧**往下掉：两眼中间那一侧要一直保持在尖上面，不然平滑的 min 会挑中它，两眼中间的 V 被挖得很深。
- 手从肩膀轴垂下来；轴的位置在轮廓里藏好（围巾底下最好），手抬起来才不会露出断口。
- 零件号（`uPart`）自己定，在 `alb()` 里按号上色；每个零件都写上 `lenK`（切成有毛时毛长几成：身子 1、手 0.9、耳朵脚 0.5–0.8、围巾 0.35），软胶也写，换皮才好看。

## 脸

`SPEC.face = { EYE: { x, y, rx, ry, rz }, MOUTH: { y, R, arc, tube } }`：眼睛是黑珠子 ＋ 画上去的白点（右上，两只一样），闭眼是一道往下弯的线，笑是往上拱的弧，嘴是一段圆弧。眼睛和嘴按 `onFace` 贴在身子表面，跟着头转。
- 身子轮廓陡（蛋形），眼睛贴歪了，就把 `SPEC.faceRelax` 调小（penguin 0.4，pink 0.7）。
- 离面多高：`SPEC.lift.<皮>`。有毛要浮在毛尖上（默认 0.05），软胶贴着面（默认 0.012）。

## 颜色和光

- `SPEC.uniforms`：颜色（`'#hex'`）和花纹参数；两种皮颜色不一样（两张原图）就写进 `SPEC.skins.<皮>.uniforms`。
- 着色器里 `alb(p, out ao)` 给每个点的底色（p 是零件自己坐标里的点）；光、暗面、底下的阴影 kit 做。
- `SPEC.look` 调光：`L` 光从哪来、`dark` / `lit` 暗面亮面乘的颜色。
  - **先看原图哪边亮**：kit 默认光从左上来（`L` 的 x 是负的）；原图右边亮就把 x 改成正的，不然左右明暗是反的。
  - **对着原图的影子调 dark**：粉色的影子是更深的玫瑰色（偏暖），绿色的影子是更深的黄绿 —— 不是灰。其余参数见 [skins.md](skins.md)。
  - 头顶那片亮：软胶的高光是跟着镜头走的一大片，原图的反光要是偏在一边、很亮，可以在 `alb()` 里画一片淡的亮带补上。

## 改到什么程度算好

`tools/overlay.py` 叠出来看图，也看它打的数字：轮廓每行的差中位数 ≤ 0.015（个别行大多半是抠图的事，看图确认）；最高点、最低点差 ≤ 0.02；眼睛、嘴的中心差 ≤ 0.02；颜色亮面看不出差别。
红线是原图里所有的边（围巾的纹、垂条的罗纹、眼睛高光都算），里面的花纹对不对要放大看，别把对的东西「改」错。
姿势表里每个动作都没有穿模（手插进头里、脚插进地里、围巾穿过身子），侧面、背面不露馅。
