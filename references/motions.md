# 动作

一帧的流程：`motion.pose(t, dt, gaze)` 算出一个姿势（一组数字）→ 模型 `apply(pose)` 摆好 → 画。网页、App、帧图都是这一条。

## 姿势字段（kit.js 的 POSE0）

| 字段 | 管什么 | 常用范围 |
|---|---|---|
| `yaw` | 整只转身（π 是背对着） | −π – π |
| `roll` | 整只左右歪 | ±0.1 |
| `dy` | 离地多高 | 0 – 0.62 |
| `sq` | 压扁（<1）/ 拉长（>1），体积不变 | 0.86 – 1.08 |
| `look` | 转头（正的往画面右） | ±0.55 |
| `nod` | 点头（正的往下） | ±0.2 |
| `tilt` | 歪头 | ±0.15 |
| `gx` `gy` | 眼睛在脸上挪 | ±0.065 |
| `blink` | 闭眼 0–1（>0.8 换成一道线） | |
| `smile` | 笑：眼睛变弯、嘴变大 | 0 / 1 |
| `mouth` `eye` `white` | 嘴多大、眼睛多大、眼睛高光多大 | 1 / 1 / 1.4 |
| `fl` `fr` | 左 / 右手往外张、往上抬（2.4 举到头侧） | 0 – 2.4 |
| `ll` `lr` | 左 / 右手往前（负的往前；手举高以后要负的才在前面） | −1 – 0 |
| `seed` | 毛轻轻抖一下（帧图每格换一个） | |

左右都是**画面上**的左右。

## 节奏（O3K，只用这些）

`w: 18`（每个通道追目标：约 170ms 到 95%）· `jump: 1.0` · `smile: 1.25` · `blink: 0.18` · `breath: 3.4` · `sway: 3.2` · `flap: 0.62` · `look 0.42 / nod 0.18 / gaze 0.03`（跟着看最多转多少）· `idleGlance: 6`。
新动作的快慢从这里挑（摆一下 = `flap`，慢慢歪 = `sway`，一次性的 = `jump` / `smile`），不另起时长和曲线。项目有自己的动效规格就先读它、先登记。

## 内置动作（core/motion.js 的 ACTIONS）

`idle` 平时 · `think` 想 · `work` 干活 · `done` 好了（跳起来笑，1.3 秒后按钮回到平时）。另外两个不在按钮上：开场（`start(t, true)`）、点它（`poke(t)`）。
每只要调的只有模型文件的 `KEY.think` / `KEY.work`：
- 「想」：一只手举到头侧挠头。**角度每只都要试，别照抄别的那只**：在姿势表里摆 4–5 组 `fr`（2.2–2.6）× `lr`（−0.5 – −1.0），挑手露在头侧、贴着头、不像挥手的那组。
  试过的：手举起来以后 `lr` 取负的才在前面；粉色那只 2.4 / −0.5；我们手搭的企鹅 2.2 / −1.0（照粉色的角度鳍整只埋进头里）；盲测时另一个人搭的企鹅 2.5 / −0.7（照 2.2 / −1.0 鳍尖朝镜头、在眼睛高度往外戳，像挥手）。往前伸到脸颊会被围巾挡住；举到半空像挥手。
- 「干活」：点头 ＋ 两只手错开着拍，一般不用改。

## 加一个新动作

写在模型文件的 `ACTIONS`（会自动出现在预览页的按钮、App 的 `state`、帧图里）：

```js
export const ACTIONS = {
  // 一直做到换走：target 给目标姿势；SMOOTH 里的通道（yaw look nod tilt gx gy fl fr ll lr）平滑地追，其余（smile、blink、sq、dy…）直接摆
  wave: { label: '挥手', kind: 'loop', period: 0.62, cells: 4,
    target: (t, K, O) => ({ fr: 1.75 + 0.22 * Math.sin(t * 2 * Math.PI / O.flap), lr: -0.6, tilt: -0.06, look: 0.06, smile: 1 }),
    still: () => ({ fr: 1.75, lr: -0.6, tilt: -0.06, look: 0.06, smile: 1 }) },
  // 做一次就回到平时：play(u) 直接摆（u 是开始后几秒），dur 秒做完，back 秒后按钮回到平时
  spin: { label: '转一圈', kind: 'once', dur: 1.0, back: 1.1,
    play: u => ({ yaw: 2 * Math.PI * (1 - (1 - Math.min(1, u)) ** 3), dy: 0.15 * Math.sin(Math.PI * Math.min(1, u)) }) },
};
```

- `period` / `cells`：出帧图时 loop 一圈采几格（不写：2 秒采 6 格）；once 每 2 格采一格。要手挑格子就写 `frames: { cells: [[名字, 姿势]…], seq: [[名字, 停几格]…] }`。
- `still`：减动效、太慢停下时停在哪一格（loop 才要）。

步骤：
1. 大白话 → 哪几个字段怎么动。先摆静止的几个角度（`window.avatarDraw({...})` 一次截几张，见 `tools/sheet.cjs`），挑看得清的那个。
2. 写进 `ACTIONS`，`KEY` 不够用的姿势也可以放 `KEY.<名字>`，让不同的角色各调各的。
3. 验：姿势表看静止那格；`tools/live.cjs` 真跑（按钮会多一个）；`tools/frames.cjs` 重出帧图，看新那几格。
4. 在模型文件注释里写一句试过不行的角度（例：挥手 `fr 1.95 / lr −0.15` 手贴着头，像在挠头，跟「想」分不出来）。

做不了的（骨架没有）：走路、跑、手指、手肘膝盖弯、尾巴甩、衣服飘、表情换形状（除了眨眼、笑、嘴大小）。
